# punpun — channel site

Persona-menu style site for the PunPun channel, based on
[Persona_style_portfolio](https://github.com/Numal400/Persona_style_portfolio) by Numal400.

- Add a video: put its YouTube ID in `videos` inside `js/model.js`.
- Social links: `index.html`, Socials section.
- Colors: CSS variables at the top of `css/style.css`.

Run locally with `python3 -m http.server`, then open http://localhost:8000
Deploy: GitHub → Settings → Pages → Deploy from branch → main → / (root).
